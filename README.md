# 빗소리 서재 (Rainy Library)

책 읽는 시간을 재면서 빗소리, 장작 타는 소리, 카페 소음을 섞어 나만의 독서 공간을 만들어 주는 앱입니다. 읽은 쪽수를 적으면 읽는 속도와 다 읽을 날짜를 알려 주고, 마음에 남은 문장도 함께 모아 둘 수 있습니다. 인터넷이 없어도 쓸 수 있고, 모든 기록은 내 휴대폰에만 저장됩니다.

A reading timer that builds your own cozy reading nook by mixing rain, crackling fire, and café sounds while you read. Log the pages you read to see how fast you're going and when you'll finish the book, and save your favorite lines along the way. It works offline, and everything stays on your own device.

**바로 쓰기:** https://poguni.github.io/rainy-library/ (휴대폰 브라우저에서 열고 '홈 화면에 추가'하면 앱처럼 쓸 수 있습니다.)

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 프로덕션 빌드
npm run test       # 테스트
```
