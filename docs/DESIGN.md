# 빗소리 서재(Rainy Library) 디자인 가이드 (DESIGN.md)

> 문서 버전 v1.0 · 2026-10-31
> 이 문서는 앱의 **두 가지 테마**를 코드로 옮길 때 지켜야 할 시각 규칙입니다.
> 함께 볼 파일:
> - `docs/design/tokens.css`: 그대로 복사해서 쓰는 디자인 토큰
> - `docs/design/paper-mockup.html`: 종이 서재 시안(타이머 홈, 서재)
> - `docs/design/emerald-mockup.html`: 에메랄드 서재 시안(타이머 홈, 서재)
>
> 시안과 이 문서가 다르면 **이 문서가 우선**합니다(대비 보정 등 시안 이후에 결정한 내용이 반영되어 있습니다).

---

## 1. 디자인 원칙

1. **책이 주인공** — 장식은 책과 서재에서 빌려 옵니다(책장, 책갈피 리본, 책등, 장정, 금박). 의미 없는 그라데이션이나 이모지는 쓰지 않습니다.
2. **읽는 동안은 조용하게** — 타이머가 돌아가는 동안 움직이는 요소는 남은 시간과 진행 링뿐입니다. 알림 배지, 깜빡임, 자동 재생 애니메이션은 없습니다.
3. **한 번에 하나의 강조** — 한 화면에서 강조색이 칠해진 주 버튼은 하나입니다.
4. **같은 구조, 다른 분위기** — 두 테마는 화면 구조와 기능이 같고, 색·글꼴·일부 부품의 모양만 다릅니다.
5. **모두가 읽을 수 있게** — 글자 대비 4.5:1 이상, 누를 수 있는 영역 44×44px 이상.

## 3. 색상

모든 색은 `tokens.css`의 CSS 변수로만 씁니다. 화면 코드에 `#52664B` 같은 값을 직접 쓰지 않습니다.

### 3.2 책등 색(서재 화면)
| 토큰 | 종이 서재 | 에메랄드 서재 |
|---|---|---|
| `--spine-1` ~ `--spine-6` | 호두 `#7A5C43`, 리넨 `#C9B48A`, 이끼 `#52664B`, 벽돌 `#9C4F3D`, 먹청 `#4A5D73`, 미색 `#DCCDB0` | 옥스블러드 `#5A1F24`, 네이비 `#1E3A5F`, 에메랄드 `#1F4A3F`, 자두 `#3B2A4A`, 옥스블러드, 흑단 `#2B2B2B` |

- 책을 등록하면 `id`를 바탕으로 6가지 중 하나를 **고정 배정**합니다(같은 책은 항상 같은 색).
- 종이 서재에서 리넨·미색 책등은 어두운 글자(`--spine-ink-dark`)를, 나머지는 밝은 글자를 씁니다.
- 시안의 호두색 `#8A6A4F`는 밝은 글자와의 대비가 4.42:1이라 `#7A5C43`(5.5:1)로 보정했습니다.

### 3.3 대비 확인 결과(WCAG)
| 조합 | 종이 서재 | 에메랄드 서재 |
|---|---|---|
| 본문 / 바탕 | 10.2 : 1 | 13.9 : 1 |
| 보조 글자 / 바탕 | 5.1 : 1 | 7.7 : 1 |
| 강조색 / 바탕 | 5.2 : 1 | 8.0 : 1 |
| 강조색 위 글자 | 5.9 : 1 | 8.0 : 1 |

새 색을 추가할 때도 글자는 4.5:1, 24px 이상 큰 글자와 아이콘은 3:1 이상을 지킵니다.

## 4. 글꼴

### 4.1 글꼴 묶음
| 역할 | 토큰 | 종이 서재 | 에메랄드 서재 |
|---|---|---|---|
| 제목, 책 제목, 인용문 | `--font-display` | Gowun Batang 400·700 | Noto Serif KR 600·700 |
| 본문, 버튼, 라벨 | `--font-body` | Gowun Dodum 400 | IBM Plex Sans KR 400·500 |
| 타이머·통계 숫자, 영문 장식 | `--font-numeral` | Gowun Batang 700 | Cormorant Garamond 500·600, 이탤릭 500 |

- 모두 SIL Open Font License라 앱에 넣어 배포할 수 있습니다.
- 오프라인 PWA이므로 Google Fonts 링크 대신 **글꼴 파일을 앱에 포함**합니다(`@fontsource` 패키지 또는 woff2 직접 포함).
- 선택한 테마의 글꼴만 불러옵니다. 한글 글꼴은 쓰는 글자만 남겨(subset) 테마당 300KB 이하로 줄입니다.

### 4.2 글자 크기
| 쓰임 | 크기 / 굵기 | 글꼴 |
|---|---|---|
| 타이머 숫자 | 54px (에메랄드 66px) / 700 (600) | numeral |
| 큰 통계 숫자(완독일, 진행률) | 34~44px / 600 | numeral |
| 화면 제목 | 21~22px / 700 | display |
| 카드 제목, 책 제목 | 17~22px / 700 | display |
| 섹션 제목 | 15px / 700 | display |
| 본문, 버튼 | 14~15px / 400 | body |
| 설명, 메타 정보 | 13px / 400 | body |
| 라벨, 탭 이름 | 12px / 400 | body |

- 한글은 `word-break: keep-all`로 단어 중간에서 줄이 바뀌지 않게 합니다.
- 숫자가 좁은 칸에 들어갈 때는 `white-space: nowrap`을 씁니다(예: "6시간 20분").
- 에메랄드의 영문 장식 문구(`RAINY LIBRARY`, `NOW READING`, `THE LAST PAGE`)는 Cormorant 12~13px, 자간 3~5px, 금색입니다. 이 문구는 장식이므로 같은 뜻의 한글을 가까이에 함께 둡니다.

## 5. 간격, 모양, 그림자

- **간격**: 4px 단위(`--space-1` 4px ~ `--space-10` 40px). 화면 좌우 여백 24px, 카드 안 여백 12~20px, 요소 사이 간격 8~18px.
- **기준 화면**: 390×844(휴대폰). 360px 폭까지 깨지지 않아야 하고, 태블릿·PC에서는 가운데 최대 폭 480px으로 보여 줍니다.
- **모서리**
  | 토큰 | 종이 서재 | 에메랄드 서재 |
  |---|---|---|
  | `--radius-md` (작은 칸) | 10px | 8px |
  | `--radius-lg` (카드) | 12px | 8px |
  | `--radius-page` (책장 카드) | 4px 16px 16px 4px | 3px 8px 8px 3px |
  | 버튼(원형) | 50% | 50% |
- **그림자**: 종이 서재는 부드러운 갈색 그림자, 에메랄드 서재는 금빛 후광(glow)입니다. 주 버튼과 선택된 책등에만 씁니다.

## 7. 공통 부품

두 테마가 **같은 마크업**을 쓰고 토큰만 바뀌는 부품입니다.

| 부품 | 규칙 |
|---|---|
| **하단 탭 바** | 4칸 균등(타이머·사운드·서재·기록), 칸당 높이 52px 이상, 아이콘 22px + 라벨 12px. 선택된 칸은 `--color-accent` + 굵게. 에메랄드는 라벨 아래 5px 금색 마름모를 추가로 표시합니다. 종이는 위쪽 1px 구분선과 `--color-surface` 바탕, 에메랄드는 바탕 없음. |
| **주 버튼(재생/일시정지)** | 지름 72px(에메랄드 76px) 원, `--color-accent` 바탕, `--color-on-accent` 아이콘, `--shadow-primary`. |
| **보조 원형 버튼** | 지름 52px, 1px `--color-line-strong` 테두리, 투명 또는 `--color-surface` 바탕. 아래에 12px 라벨(종이) 또는 라벨 생략 + `aria-label`(에메랄드). |
| **텍스트 버튼·링크** | `--color-accent`(종이) / `--color-accent-strong`(에메랄드), 높이 44px. |
| **필터 칩** | 높이 36px, 둥근 알약 모양. 선택: `--color-ink` 바탕 + `--color-surface` 글자. 미선택: 1px 테두리. |
| **진행 막대** | 높이 8px(종이) / 3px(에메랄드), 바탕 `--color-track`, 채움 `--color-accent`. |
| **통계 칸** | 라벨(12px, muted) + 값(16~24px, numeral). 종이는 `--color-surface-sunken` 둥근 칸 3개, 에메랄드는 위아래 선과 세로 구분선으로 나눈 3칸. |

| **바텀 시트**(세션 종료, 책 추가) | 위쪽 모서리 16px, `--color-surface-raised` 바탕, 손잡이 막대 36×4px, 배경 어둡게 40%. |
| **입력칸**(쪽수 등) | 높이 48px, 숫자 키패드(`inputmode="numeric"`), 옆에 −/+ 버튼(44px), 반드시 `<label>` 연결. |

## 8. 테마 전용 부품

모양이 크게 달라 **테마마다 따로 그리는** 부품 4종입니다. 데이터와 동작은 공통 훅에서 받고, 부품은 그리기만 합니다.

```tsx
// 화면에서는 공통 이름으로 씁니다.
<TimerFace remainingSec={1122} totalSec={1500} round={2} rounds={4} phase="focus" />
<SoundControls layers={layers} onChange={setVolume} />
<FinishCard date="2026-11-14" remainingMin={241} />
<BookSpine book={book} selected />
// 실제로 그려지는 것은 현재 테마의 variants/paper/* 또는 variants/emerald/* 입니다.
```

### 8.1 타이머 표시 `TimerFace`
| | 종이 서재 | 에메랄드 서재 |
|---|---|---|
| 바탕 | 책장 카드(`--radius-page`) 뒤로 종이 2장이 4px, 8px씩 비켜 겹쳐 보임 | 카드 없음, 화면 바탕 위에 바로 다이얼 |
| 장식 | 오른쪽 위에 책갈피 리본(22×78px, 아래가 V자로 파임, `--color-ribbon`) | 바깥 금선 원 → 1분 눈금(60개) → 5분 굵은 눈금(12개) → 진행 링 → 안쪽 원판, 12시 방향 금색 마름모 |
| 링 | 지름 208px, 굵기 7px, 둥근 끝 + 안쪽 점선 원 | 지름 268px, 진행 링 굵기 3px |
| 글자 | 위: "집중 시간 · 2 / 4회차" / 가운데: 18:42 / 아래: "남은 시간 / 25분" + 책 속 한 문장(선택) | 위: `FOCUS · II / IV`(로마 숫자) / 가운데: 18:42 / 아래: "남은 시간" |
| 휴식 중 | 링 색을 `--color-ink-muted`로, 라벨 "쉬는 시간" | 링 색을 `--color-accent-strong`으로, 라벨 `REST` |

- 진행 링은 SVG `circle`의 `stroke-dasharray`로 그리고, 12시 방향에서 시계 방향으로 채웁니다.
- 숫자는 1초마다 바뀌지만 링은 부드럽게 움직이지 않아도 됩니다(배터리 절약). `prefers-reduced-motion`이면 전환 효과를 끕니다.
- 숫자에는 `font-variant-numeric: tabular-nums`를 써서 1초마다 글자 폭이 흔들리지 않게 합니다.

### 8.2 환경음 컨트롤 `SoundControls`
| | 종이 서재 | 에메랄드 서재 |
|---|---|---|
| 홈 화면(요약) | 3칸 카드: 아이콘 + 이름 / 가는 막대(4px) / 퍼센트 | 원형 메달 4개(빗소리·장작·카페·음악): 지름 62px 원판 + 둘레 금색 호가 음량, 아래에 "빗소리 60" |
| 사운드 탭(전체) | 소리마다 한 줄: 아이콘, 이름, 켜기 스위치, 가로 슬라이더 | 소리마다 큰 메달(지름 88px) 2열 배치, 메달을 누르면 켜기/끄기, 아래 슬라이더 |
| 꺼진 소리 | 글자 `--color-ink-muted`, 막대 비움 | 메달 투명도 50%, 호 없음 |

- 슬라이더는 반드시 `<input type="range">`로 만들고 `aria-label="빗소리 음량"`과 같은 이름을 붙입니다(모양만 바꾸고 기본 요소는 유지).

## 9. 테마별 화면 장식

| 장식 | 종이 서재 | 에메랄드 서재 |
|---|---|---|
| 화면 테두리 | 없음 | 화면 안쪽 10px, 15px 위치에 금 이중선(투명도 45%, 20%). `--frame-display`로 켜고 끔. 클릭을 막지 않도록 `pointer-events: none` |
| 머리말 | 왼쪽 정렬 "빗소리 서재" + 오늘의 한 줄("금요일 저녁, 창밖엔 비") | 가운데 `RAINY LIBRARY` + "빗소리 서재" + 선─마름모─선 장식 |
| 책 제목 표기 | 데미안 | 『데미안』 |
| 영문 부제 | 사용 안 함 | Cormorant 이탤릭(예: *Hermann Hesse — 120쪽부터*) |

- "오늘의 한 줄"은 요일과 시간대(아침·오후·저녁·밤)에 따라 미리 정한 문장 중 하나를 보여 줍니다. 날씨 정보는 쓰지 않습니다(오프라인 우선).

## 10. 테마 전환

- 설정 > 테마: 미리보기 카드 3개(종이 서재 / 에메랄드 서재 / 자동). 카드는 실제 토큰으로 그린 작은 타이머 그림입니다.
- 바꾸면 즉시 `<html data-theme="…">`가 바뀌고, 색은 200ms 동안 부드럽게 넘어갑니다. 진행 중인 타이머와 소리는 그대로 유지됩니다.
- 자동 모드는 `prefers-color-scheme`(기본) 또는 지정 시각(19:00~07:00)을 따릅니다. 앱을 쓰는 도중에는 갑자기 바뀌지 않게, **앱을 다시 열거나 화면으로 돌아올 때만** 다시 계산합니다.
- 저장된 테마는 `index.html`의 인라인 스크립트로 첫 화면 전에 적용합니다(깜빡임 방지). 이 값은 IndexedDB보다 빨리 읽을 수 있도록 `localStorage`에도 함께 저장합니다.
- `<meta name="theme-color">`를 `--theme-color-meta` 값으로 바꿉니다.

## 12. 글쓰기(화면 문구)

- 존댓말, 짧고 따뜻하게. 예: "기록이 더 쌓이면 알려 드릴게요", "마지막 장을 덮어요".
- 숫자 단위는 붙여 씁니다: 142쪽, 25분, 0.44쪽/분. 시간은 "6시간 20분"(에메랄드의 큰 숫자 칸은 `6h 20m` 허용).
- 날짜: "11월 14일 (토)". 에메랄드의 장식 숫자는 `11 · 14`.
- 버튼은 동사로: 시작하기, 끝내기, 쉬어가기, 책 추가.

## 13. 하지 말 것

- 화면 코드에 색상값·글꼴 이름을 직접 쓰기(반드시 토큰 사용)
- 테마 전용 부품 안에 저장·계산 로직 넣기(공통 훅에만)
- 그라데이션 배경, 이모지 아이콘, 왼쪽 굵은 색 띠 카드
- `div`에 `onClick`만 달아 버튼 흉내 내기(반드시 `<button>`)
- 에메랄드 테마에서 금색을 넓은 면에 칠하기(금색은 선, 글자, 주 버튼 하나에만)
- 휴대폰 상태 표시줄(시계·배터리)을 화면에 그려 넣기
