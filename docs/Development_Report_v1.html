1. 개요

항목내용
앱 이름빗소리 서재 (Rainy Library)
한 줄 소개책 읽는 시간을 재고(뽀모도로), 빗소리·장작·카페 소리를 섞어 '나만의 독서 공간'을 만들어 주는 오프라인 우선 PWA
대상 사용자퇴근 후 꾸준히 읽고 싶은 직장인, 전공서를 오래 읽는 수험생·대학원생, 읽은 시간과 책을 기록하는 것을 즐기는 독서 기록가
개발 기간2026-11-01 ~ 2026-11-02 (0~5단계, Claude Code와 바이브 코딩)
현재 상태MVP 완성(PRD 4장 v1.0 범위). v1.1(음악 재생 목록, 프리셋, 통계, 에메랄드 테마)은 남음

2. 목표 및 배경

  • 책을 읽으려 해도 알림과 소음 때문에 집중이 오래가지 않고, 타이머·백색소음·음악·독서 기록 앱을 따로따로 써야 해서 번거롭습니다.
  • "이 책을 언제 다 읽을까?", "나는 한 시간에 몇 쪽을 읽지?"에 답해 주는 도구가 드뭅니다.
  • 그래서 버튼 한 번으로 집중 환경(소리 + 타이머)을 켜고, 읽은 만큼 기록이 자동으로 쌓이는 앱을 목표로 했습니다.
  • 모든 데이터는 기기 안에만 저장하고, 인터넷 없이도 모든 기능이 동작하는 것을 원칙으로 삼았습니다.
  • 학습 목표: PWA, Web Audio API, IndexedDB를 실제로 다뤄 보기.

4.3 핵심 구조

  • 타이머: 화면 갱신만 1초마다 하고, 시간은 항상 "구간 시작 시각 + 일시정지 누적"으로 Date.now()에서 계산합니다. 앱을 오래 닫아 두었다 열면 그사이 지나간 집중·휴식 구간을 모두 따라잡습니다. 타이머 상태는 앱 전체 Context로 두어 어느 탭에 있어도 전환 알림과 소리 페이드가 동작합니다.
  • 오디오 연결: 소리별 BufferSource(반복) → 소리별 Gain → 마스터 Gain → 단계 Gain(재생/정지, 집중·휴식 페이드) → Compressor → 스피커. AudioContext는 앱 전체에 하나입니다.
  • 데이터: books, sessions, presets, tracks, settings 5개 저장소(스키마 버전 1). 진행 중인 세션만 새로고침 직후 바로 복원하려고 localStorage에 둡니다.
  • 테마: <html data-theme>와 CSS 변수로 전환합니다. 테마마다 모양이 다른 부품은 TimerFace, SoundControls, FinishCard, BookSpine 4종뿐이고, theme/parts.ts 한 곳에서 고릅니다(지금은 종이 서재만).

6. 주요 의사결정과 이유

결정이유
라우터는 react-router-dom(HashRouter)탭 주소·뒤로 가기·책 상세 주소가 필요하고, 정적 호스팅에서도 새로고침이 깨지지 않음(사용자 확인)
Tailwind v4 @theme inline reference로 토큰 연결, 기본 색 팔레트 끔토큰 이름과 Tailwind 변수가 같아 생기는 자기 참조를 없애고, 토큰 외 색을 쓸 수 없게 함
진행 중인 세션은 localStorageIndexedDB는 비동기라 새로고침 직후 타이머가 잠깐 비어 보임. 완료된 기록은 IndexedDB
완독일의 하루 평균은 '그 책'의 최근 14일 시간여러 책을 함께 읽을 때 더 정확하고, 시안의 "11월 14일"과 일치
책 상세의 평균 속도는 PRD 6.1 식(책 전체)시안의 0.44는 최근 5회 값. 완독일 계산에는 최근 5회 속도 사용
휴식 중 환경음은 30%로 줄임(끄지 않음)쉬는 동안에도 분위기를 유지. BREAK_LEVEL 하나로 조정 가능
타이머 상태를 앱 전체 Context로 이동다른 탭에 있으면 전환 알림·페이드가 멈추던 문제 해결
환경음은 −23 LUFS로 맞추고 원본은 따로 보관파일 간 최대 15dB 차이. 원본은 sound-originals/(GitHub 제외), 스크립트로 언제든 재가공
켜진 소리만 불러오기5종 스테레오를 모두 풀면 휴대폰 메모리 100MB 이상 사용
음원 형식은 m4a(AAC)만크롬·사파리·엣지·삼성 인터넷 모두 재생. ogg 중복 보관 불필요
글꼴은 직접 서브셋(2,350자 + 앱 글자)오프라인 우선이라 Google Fonts 링크 대신 앱에 포함. npm 패키지 추가 없이 fonttools 사용
화면 꺼짐 방지를 5단계로 앞당김설정 화면에 스위치만 있고 동작하지 않으면 혼란
저작권 표시를 화면에 하지 않음사용자 요청(제작자 안내: 표시 불필요). 제작자 재확인 중

7. 문제 해결 기록

문제원인해결
Prettier가 CLAUDE.md·START_HERE.md 표 모양을 바꿈전체 폴더에 서식 적용키트 zip 원본으로 되돌리고 .md·.html을 Prettier 대상에서 제외
Tailwind 변수 자기 참조(--color-surface: var(--color-surface))토큰 이름과 Tailwind 테마 변수 이름이 같음@theme inline reference로 변수 출력 자체를 막음
다른 탭에서 전환 알림·소리 페이드가 멈춤타이머 상태가 타이머 화면 안에만 있었음TimerProvider(Context)로 앱 전체에 공유
반복 지점의 '툭' 소리(장작 이음새 튐 0.12)음원 끝과 처음의 파형이 이어지지 않음불러올 때 1초 equal-power 크로스페이드 → 0.0015로 감소
처마 끝 빗소리가 반복마다 잠깐 꺼짐(예상)원본 앞 1.5초 페이드 인앞 2초를 잘라 냄
귀뚜라미가 거의 들리지 않음(예상)음원 간 음량 차이 최대 15dB다섯 개 모두 −23 LUFS(±0.7)로 맞춤
늦게 불러온 소리가 갑자기 튀어나올 수 있음공용 ramp 함수가 직전 예약값을 지움그 자리만 직접 0에서 0.5초 동안 올리도록 수정
설정의 라디오·스위치가 누른 직후 잠깐 되돌아감저장 후 다시 읽어 와야 화면이 바뀜화면을 먼저 바꾸고 저장은 뒤에서. 회귀 테스트 추가
서비스 워커 사전 캐시에 아이콘이 중복플러그인의 자동 아이콘 추가와 파일 패턴이 겹침includeManifestIcons: false, 20개·중복 0
테스트에서 처리되지 않은 오류jsdom에 IndexedDB가 없어 믹서 설정 불러오기 실패엔진 초기화에 오류 처리 추가(기본 조합으로 동작)
lint: effect 안에서 setState표지 이미지 주소를 state로 관리ref로 img에 직접 넣는 BlobImage 컴포넌트로 교체

8. 보안·개인정보·성능

  • 개인정보: 책·세션·설정·음악은 모두 기기(IndexedDB·localStorage)에만 저장합니다. 외부 서버 전송, 분석 도구, 광고 SDK가 없습니다.
  • 외부 요청 없음: 글꼴·아이콘·음원을 모두 앱에 포함해, 설치 후에는 네트워크 요청이 필요 없습니다.
  • 메모리: 환경음은 켜진 것만 디코딩합니다(소리당 약 23MB).
  • 설치 용량: 사전 캐시 20개 파일, 약 4.8MB(대부분 환경음). JS 약 331KB(gzip 107KB).
  • 개발용 기능 분리: 샘플 데이터 버튼과 window.__soundEngine은 개발 모드에서만 존재하고 배포판에는 빠집니다(빌드 결과에서 확인).

9. 테스트 및 검증

9.1 자동 테스트

10. 배포

  • 아직 배포하지 않았습니다. npm run build로 dist/를 만들고 npm run preview로 확인할 수 있습니다.
  • HashRouter와 상대 경로 manifest(start_url: ./)를 써서 GitHub Pages·Netlify·Vercel 어디에 올려도 동작하도록 준비해 두었습니다. PWA는 HTTPS가 필요합니다.

11. 알려진 한계

  • 글꼴 용량: 종이 서재 글꼴 합계 506KB로 PRD 목표(테마당 300KB)를 넘습니다. 한 번 저장되면 이후에는 영향이 없습니다.
  • 새로고침 후 소리: 세션 중 새로고침하면 타이머는 이어지지만 소리는 꺼진 채로 돌아옵니다(브라우저 자동 재생 정책). 사운드 탭에서 다시 켜야 합니다.
  • 일시정지 중 소리: 일시정지해도 환경음은 계속 나옵니다(PRD에 정해진 내용 없음).
  • 책 제목의 드문 한글: 2,350자 밖의 글자는 기본 글꼴로 보입니다.
  • 책등 폭: DESIGN.md의 26~42px를 따라 누르는 영역이 44px보다 좁습니다.
  • DB 연동 화면 테스트 없음: jsdom에 IndexedDB가 없어 서재·타이머 화면의 저장 흐름은 브라우저에서 수동 확인했습니다.
  • Lighthouse PWA 항목: Lighthouse 12부터 PWA 카테고리가 없어져, 크롬 설치 가능성 검사로 대신했습니다.
  • 시스템 알림: 앱이 화면에 보이지 않을 때만 띄웁니다. iOS는 홈 화면에 설치한 경우에만 알림이 됩니다.
  • 화면 꺼짐 방지: iOS 16.4 미만 등 지원하지 않는 브라우저에서는 동작하지 않습니다(설정 화면에 안내).
  • 아주 짧은 세션도 기록됨: 시작 직후 끝내도 0분 세션이 저장됩니다(속도 계산에서는 빠짐).
  • 앱 아이콘: Claude가 만든 초안입니다.

12. 향후 개선 아이디어 / 업데이트 계획

12.1 ⚠️ 확인이 필요한 일 (잊지 말 것)

  • 환경음 5종 저작권 재확인: 창밖 빗소리, 처마 끝 빗소리, 장작, 카페, 귀뚜라미는 유튜브에서 구한 음원입니다. 제작자 안내는 "상용 목적이 아니면 자유 사용, 저작권 표시 불필요"였고, 사용자가 댓글·메일로 다시 확인을 요청한 상태입니다(음원이 몇 년 된 것이라 답이 늦을 수 있음).
    • "비상업 목적만 허용"은 ASSETS.md가 피하라고 한 비상업(NC) 조건에 해당합니다. 개인·포트폴리오용으로는 괜찮지만, 유료 판매나 광고를 붙이면 음원을 바꿔야 합니다.
    • 답을 받으면 docs/ASSETS.md 출처 표를 채웁니다(화면 표시는 하지 않기로 함).
  • 글꼴 용량 방침 결정: 그대로 둘지(권장), 고운바탕 굵은 글꼴을 빼거나 글자 수를 줄일지.
  • 실제 기기 확인: 안드로이드·아이폰에서 설치, 소리, 알림, 화면 꺼짐 방지.
