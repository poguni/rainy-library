**내보내기 구성(2026-11-02 사용자 결정)**
기록 탭(또는 설정)의 "내 기록 내보내기"에서 세 가지를 고를 수 있게 합니다.

| 용도 | 형식 | 내용 |
|---|---|---|
| 컴퓨터용: 백업·복원 | JSON | 책·세션·프리셋·설정 전부. 표지 사진은 포함, 음악 파일은 용량 때문에 제외(또는 따로) |
| 컴퓨터용: 연대기 연동 | JSON | PRD 8.3 `reading-log/v1` 형식 |
| 사람용: 표 | **xlsx** | 아래 시트 구성 |
| 사람용: 문서 | 인쇄용 화면 → PDF | 책별 요약 + 기간별 독서 기록. A4 인쇄용 CSS, "인쇄 / PDF로 저장" 버튼(`window.print()`). 앱에 들어 있는 한글 글꼴을 그대로 사용 |

**엑셀(xlsx) 파일 규칙**
- 시트 1 "책 목록": 제목, 저자, 상태, 전체 쪽수, 현재 쪽수, 진행률(%), 누적 독서 시간(분), 세션 수, 평균 속도(쪽/분), 완독 예상일, 등록일
- 시트 2 "독서 기록": 날짜, 시작 시각, 끝난 시각, 책 제목, 시작 쪽수, 끝 쪽수, 읽은 쪽수, 독서 시간(분), 속도(쪽/분), 방식(뽀모도로/자유)
- **열 폭은 넉넉하고 보기 좋게**(사용자 요청): 글자 수에 맞춰 자동으로 정하되 한글은 영문 2글자로 세고, 여유 2~4칸을 더합니다. 최소 10, 최대 50 정도(긴 책 제목은 줄바꿈).
- 첫 줄(머리글)은 굵게 + 옅은 바탕색, 틀 고정(스크롤해도 보이게), 자동 필터.
- 숫자 형식: 쪽수·분은 정수, 속도는 소수 둘째 자리(0.00), 진행률은 %, 날짜·시각은 엑셀 날짜 형식(정렬 가능하게).
- 파일 이름 예: `빗소리서재_독서기록_2026-11-02.xlsx`
- ⚠️ xlsx를 만들려면 **새 라이브러리가 필요**합니다(CLAUDE.md 규칙: 추가 전에 이유를 말하고 확인받기). 열 폭·굵은 글씨·틀 고정을 지원해야 하므로 후보는 `exceljs` 또는 `write-excel-file`. 내보내기 버튼을 누를 때만 불러오게(dynamic import) 해서 앱 첫 로딩에는 영향이 없게 하고, 오프라인에서도 되도록 서비스 워커 캐시에 들어가는지 확인합니다.

**완료 기준**
- 백업 파일로 다른 브라우저에 복원하면 책·세션·프리셋이 그대로 보인다.
- 내보낸 JSON이 PRD 8.3 형식과 일치한다(`schema: "reading-log/v1"`).
- 내보낸 xlsx를 엑셀·구글 시트에서 열면 한글이 깨지지 않고, 열 폭이 내용보다 좁아 잘리는 칸이 없다(책 제목·날짜 포함). 머리글이 고정되고 필터가 걸려 있다.
- 인쇄용 화면을 "PDF로 저장"하면 A4에 맞게 나오고 한글이 깨지지 않는다.
- 오프라인에서도 세 가지 내보내기가 모두 동작한다.
