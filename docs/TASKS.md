# TASKS.md — 빗소리 서재 작업 순서

Claude Code에게 한 번에 **한 단계**씩 맡기세요. 각 단계에는 관련 요구사항 ID(PRD), 할 일, 완료 기준, 그대로 붙여 넣을 수 있는 요청 문장이 있습니다.
단계가 끝나면 완료 기준을 직접 확인하고, 체크박스를 `[x]`로 바꿉니다.

## 2단계 · 타이머와 세션 기록 (약 1.5일) — T-01~T-05, P-01~P-04
- [x] `lib/timer.ts`: 시작 시각·일시정지 누적 시간으로 남은 시간 계산 + 단위 테스트
- [x] 뽀모도로(25/5/15, 4회마다 긴 휴식)와 자유 모드
- [x] 진행 중인 세션을 저장해 새로고침 후에도 이어짐
- [x] 세션 시작 시 시작 쪽수(직전 끝 쪽수 자동 입력), 종료 시 끝 쪽수 입력 시트
- [x] 집중·휴식 전환 알림음과 시스템 알림(권한 허용 시)
- [x] `TimerFace`(종이 서재 모양), 타이머 홈 화면 완성

**완료 기준**
- 타이머를 켜고 새로고침하거나 다른 탭에 갔다 와도 남은 시간이 맞다(1분당 ±1초).
- 일시정지한 시간은 독서 시간에 들어가지 않는다.
- 끝 쪽수가 시작 쪽수보다 작거나 전체 쪽수보다 크면 경고가 뜬다.
- 타이머 홈 화면이 `paper-mockup.html`의 타이머 화면과 비슷하게 보인다.

## 3단계 · 읽기 속도와 완독 예상일 (약 0.5일) — P-03, B-04
- [x] `lib/reading.ts`: 세션 속도, 책 평균 속도, 완독 예상일(PRD 6장) + 단위 테스트
- [x] 세션 종료 결과 요약("22쪽 / 50분 → 0.44쪽/분")
- [x] `FinishCard`(종이 서재 모양), 책 상세에 표시

**완료 기준**
- 테스트 예: 남은 106쪽, 평균 0.44쪽/분, 하루 평균 30분 → 남은 시간 약 241분, 남은 일수 9일.
- 3분 미만 세션과 쪽수 없는 세션은 속도 계산에서 빠진다.
- 기록이 3회 미만이면 "기록이 더 쌓이면 알려 드릴게요"가 보인다.

- 타이머를 시작하면 소리가 서서히 커지고, 휴식으로 바뀌면 서서히 작아진다.
