> 독서 집중 타이머 & 배경음악 믹서 · 아이디어 4-10  
> 문서 버전 v0.3 · 최종 수정 2026-10-31 · 상태: 초안(테마 기능 추가)  
> 앱 이름: **빗소리 서재** · 영문 **Rainy Library** — 비 오는 날 서재에 앉아 있는 듯한 독서 공간  
> 함께 보는 문서: `DESIGN.md`(디자인 규칙), 디자인 시안 HTML 2종, `CLAUDE.md`(개발 지침), `TASKS.md`(작업 순서), `ASSETS.md`(소리·글꼴 준비)

## 1. 개요

### 1.1 한 줄 소개
**책 읽는 시간을 재고, 빗소리·장작·카페 소음과 내 음악을 섞어 '나만의 독서 공간'을 만들어 주는 PWA.**

### 1.2 배경과 문제
- 책을 읽으려고 앉아도 휴대폰 알림, 주변 소음 때문에 집중이 오래가지 않습니다.
- 타이머 앱, 백색소음 앱, 음악 앱, 독서 기록 앱을 **따로따로** 써야 해서 번거롭습니다.
- "이 책을 언제 다 읽을 수 있을까?", "나는 한 시간에 몇 쪽을 읽지?" 같은 질문에 답해 주는 도구가 드뭅니다.

### 1.3 목표
| 구분 | 목표 |
|---|---|
| 사용자 목표 | 버튼 한 번으로 집중 환경(소리 + 타이머)을 켜고, 읽은 만큼 기록이 자동으로 쌓인다. |
| 제품 목표 | 타이머·환경음·독서 기록을 하나로 묶은 **오프라인 우선** 독서 도구를 만든다. 분위기가 다른 **두 가지 테마** 중 사용자가 골라 쓴다. |
| 학습 목표 | 바이브 코딩으로 PWA, Web Audio API, IndexedDB를 실제로 다뤄 본다. |

### 1.4 하지 않을 것(Non-goals)
- 전자책 뷰어 기능(책 본문을 앱에서 읽는 기능)은 만들지 않습니다.
- 스트리밍 음악 서비스 연동(멜론, 스포티파이 등)은 하지 않습니다.
- 회원 가입, 서버, 소셜 기능은 MVP에서 제외합니다. 모든 데이터는 기기에 저장합니다.

## 3. 핵심 사용 시나리오

1. **세션 시작**: 사용자가 앱을 열고 '읽는 중인 책'을 고른 뒤 시작 쪽수(예: 120쪽)를 확인합니다. 저장된 사운드 프리셋 '비 오는 카페'를 누르고 **[시작]** 을 누릅니다.
2. **집중**: 25분 타이머가 돌아가는 동안 빗소리 60%, 카페 소음 30%, 피아노 연주곡이 흐릅니다. 화면은 꺼지지 않고, 잠금 화면에서도 소리가 계속됩니다.
3. **휴식**: 타이머가 끝나면 부드러운 종소리와 함께 소리가 서서히 줄어들고 5분 휴식이 시작됩니다.
4. **세션 종료**: 사용자가 끝 쪽수(예: 142쪽)를 입력하면 "22쪽 / 50분 → **0.44쪽/분**"이 계산되고, "이 속도라면 **11월 14일**에 완독"이라고 알려 줍니다.
5. **기록 반영**: 세션 기록이 책별 누적 시간에 더해지고, 4-1 독서 연대기 앱으로 내보낼 수 있는 형태로 저장됩니다.
6. **테마 바꾸기**: 낮에는 따뜻한 '종이 서재' 테마로 읽다가, 밤 7시가 지나 앱을 다시 열면 자동으로 어두운 '에메랄드 서재' 테마로 바뀌어 눈이 편안합니다. 설정에서 원하는 테마로 고정할 수도 있습니다.

## 6. 계산 로직

### 6.1 읽기 속도
```
세션 속도(쪽/분) = (끝 쪽수 − 시작 쪽수) ÷ 독서 시간(분)
책 평균 속도      = 책의 총 읽은 쪽수 ÷ 책의 총 독서 시간(분)
```
- 독서 시간은 **집중 시간만** 포함하고, 휴식과 일시정지는 뺍니다.
- 3분 미만 세션이나 쪽수를 입력하지 않은 세션은 속도 계산에서 제외합니다.

### 6.2 완독 예상일
```
남은 쪽수       = 전체 쪽수 − 현재 쪽수
남은 시간(분)   = 남은 쪽수 ÷ 최근 평균 속도(최근 5개 세션)
하루 평균 독서량 = 최근 14일 독서 시간 합계 ÷ 14
남은 일수       = 올림(남은 시간 ÷ 하루 평균 독서량)
완독 예상일     = 오늘 + 남은 일수
```
- 기록이 3개 세션 미만이면 "기록이 더 쌓이면 알려 드릴게요"라고 표시합니다.
- 화면 예시: "지금 속도라면 **약 4시간 10분** 더 읽으면 완독, **11월 14일** 예상"

## 7. 화면 구성

```
하단 탭 4개
├─ ① 타이머(홈)
│   ├─ 현재 책 카드(표지, 제목, 진행률)
│   ├─ 원형 타이머 + 시작/일시정지 버튼
│   ├─ 빠른 프리셋 버튼 줄
│   └─ 세션 종료 시트(끝 쪽수 입력 → 결과 요약)
├─ ② 사운드
│   ├─ 환경음 카드(아이콘 + 볼륨 슬라이더)
│   ├─ 프리셋 저장/불러오기
│   └─ 내 음악 재생 목록
├─ ③ 서재
│   ├─ 책 목록(읽는 중 / 완독 / 보류 필터)
│   └─ 책 상세(누적 시간, 평균 속도, 완독 예상일, 세션 기록)
└─ ④ 기록
    ├─ 주간·월간 그래프, 독서 달력
    └─ 설정(테마 선택 포함) · 백업 · 연대기 내보내기
```

**디자인 방향**: 두 가지 테마를 제공합니다(5.8절). 종이 서재는 따뜻한 종이색과 이끼색, 에메랄드 서재는 짙은 녹색 가죽과 금박이 중심입니다. 두 테마 모두 타이머 중에는 화면 요소를 최소화하는 '몰입 모드'를 씁니다. 화면별 모습은 디자인 시안 HTML 2종을 기준으로 합니다.

## 9. 기술 구조

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Vite + React(또는 Svelte) + TypeScript | 바이브 코딩에 친숙하고 빌드가 빠름 |
| 스타일 | Tailwind CSS + CSS 변수(디자인 토큰) | 빠른 UI 구성, 테마 전환은 변수 교체만으로 처리 |
| 저장소 | IndexedDB(Dexie.js) | 오디오 파일(Blob)까지 저장 가능 |
| 오디오 | Web Audio API | 여러 소리를 실시간으로 섞고 볼륨·페이드 제어 |
| 오프라인 | Service Worker(vite-plugin-pwa / Workbox) | 앱과 환경음 캐시 |
| 그래프 | Chart.js 또는 Recharts | 통계 화면 |
| 배포 | GitHub Pages / Netlify / Vercel | 무료, HTTPS 기본 제공(PWA 필수 조건) |

### 9.1 오디오 연결 구조
```
[빗소리 AudioBufferSource(loop)] → [GainNode] ─┐
[장작   AudioBufferSource(loop)] → [GainNode] ─┤
[카페   AudioBufferSource(loop)] → [GainNode] ─┼→ [마스터 GainNode] → [DynamicsCompressor] → 스피커
[내 음악 <audio> MediaElementSource] → [GainNode] ─┘
```
- 환경음은 `AudioBuffer`로 미리 디코딩해 `loop = true`로 끊김 없이 반복합니다.
- 볼륨 변경과 페이드는 `gain.linearRampToValueAtTime()`으로 부드럽게 처리합니다.
- 브라우저 정책상 오디오는 **사용자가 버튼을 누른 뒤에만** 시작할 수 있으므로 `[시작]` 버튼에서 `AudioContext.resume()`을 호출합니다.
- 갈색·백색 소음은 파일 없이 코드로 생성(노이즈 버퍼)해 용량을 줄입니다.

### 9.2 테마 구조
```
src/theme/
├─ tokens.css          ← :root[data-theme="paper"], :root[data-theme="emerald"] 변수 정의
├─ themes.ts           ← 테마 목록, 글꼴 주소, theme-color 값
├─ useTheme.ts         ← 선택값 저장, 자동 모드 계산, <html data-theme> 갱신
└─ variants/           ← 테마 전용 부품
   ├─ paper/  TimerFace · SoundControls · FinishCard · BookSpine
   └─ emerald/ TimerFace · SoundControls · FinishCard · BookSpine
```
- 화면은 `<TimerFace />`처럼 공통 이름으로 부품을 쓰고, 실제로 어떤 모양을 그릴지는 현재 테마가 정합니다.
- Tailwind 설정에서 색 이름(`bg`, `surface`, `ink`, `accent` 등)을 CSS 변수에 연결해 `bg-surface text-ink`처럼 씁니다.
- `index.html`의 작은 인라인 스크립트가 저장된 테마를 읽어 `<html data-theme>`를 먼저 설정합니다(깜빡임 방지).

### 9.3 사용할 브라우저 API
Web Audio API, Media Session API, Screen Wake Lock API, Notifications API, File 입력(`<input type="file" multiple accept="audio/*">`), IndexedDB, Service Worker
