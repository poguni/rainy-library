# ASSETS.md — 소리·글꼴·아이콘 준비 목록

코드 밖에서 **직접 준비해야 하는 파일**과 그 조건을 정리했습니다. Claude Code는 이 파일들을 만들 수 없거나(음원) 라이선스를 확인할 수 없으므로, 아래 표의 '준비'와 '라이선스 확인'은 사람이 해 주세요.

---

## 1. 환경음

| 파일 이름 | 내용 | 길이 | 우선순위 |
|---|---|---|---|
| `rain.ogg` / `rain.m4a` | 창밖 빗소리(천둥 없음, 일정한 굵기) | 30~60초 반복 구간 | MVP |
| `fire.ogg` / `fire.m4a` | 벽난로 장작 타는 소리(가끔 탁탁) | 30~60초 | MVP |
| `cafe.ogg` / `cafe.m4a` | 카페 웅성거림(알아들을 수 있는 말소리 없음), 잔 부딪히는 소리 약간 | 60초 | MVP |
| `waves.*` | 잔잔한 파도 | 60초 | v1.2 |
| `forest.*` | 숲속 새소리 | 60초 | v1.2 |
| `library.*` | 도서관(책장 넘기는 소리, 아주 작은 발소리) | 60초 | v1.2 |
| 백색·갈색 소음 | 파일 없이 코드로 생성 | — | v1.2 |

**파일 조건**
- 형식: `.ogg`(Opus, 96kbps)와 `.m4a`(AAC, 96kbps) 두 가지. 사파리 호환 때문에 m4a도 필요합니다.
- 크기: 소리당 1MB 이하, 모노 또는 스테레오 44.1kHz.
- **반복 지점 처리**: 끝과 처음이 자연스럽게 이어지도록 끝 1~2초를 처음과 겹쳐(crossfade) 잘라 둡니다. Audacity로 할 수 있습니다.
- 음량: 세 소리의 체감 음량을 비슷하게 맞춥니다(약 −23 LUFS).
- 위치: `src/assets/sounds/`

**어디서 구하나**
- Freesound: 검색 필터에서 라이선스를 **Creative Commons 0**으로 거르기
- Pixabay 효과음: 무료, 상업적 이용 가능(자체 라이선스, 출처 표시 권장)
- 직접 녹음: 휴대폰으로 녹음해도 충분합니다. 가장 확실한 방법입니다.
- ⚠️ "비상업용(NC)" 또는 "변경 금지(ND)" 라이선스 음원은 쓰지 않습니다.

**출처 기록**: 음원을 넣을 때마다 아래 표를 채우고, 앱의 '정보' 화면에도 같은 내용을 보여 줍니다.

| 파일 | 원본 제목 | 만든 사람 | 출처 주소 | 라이선스 | 수정 내용 |
|---|---|---|---|---|---|
| rain_1 (창밖 빗소리) | | 유튜브 Relax Sleep ASMR | | 비상업 허락(재확인 중) | 60초로 자름, −23 LUFS |

| fire (장작) | | 유튜브 Slow TV | | 비상업 허락(재확인 중) | 60초로 자름, −23 LUFS |

## 2. 알림음

| 파일 | 용도 | 조건 |
|---|---|---|
| `chime-focus-end.*` | 집중 끝 → 휴식 | 부드러운 종소리, 2초 이내 |

## 3. 글꼴 (모두 SIL Open Font License)

| 테마 | 글꼴 | 굵기 | npm 패키지 예 |
|---|---|---|---|
| 종이 서재 | Gowun Batang | 400, 700 | `@fontsource/gowun-batang` |
| 종이 서재 | Gowun Dodum | 400 | `@fontsource/gowun-dodum` |
| 에메랄드 서재 | Noto Serif KR | 600, 700 → **600만 넣음**(700 자리에도 600, 용량 −345KB) | `@fontsource/noto-serif-kr` |
| 에메랄드 서재 | IBM Plex Sans KR | 400, 500 → **400만 넣음**(용량 −124KB) | `@fontsource/ibm-plex-sans-kr` |
| 에메랄드 서재 | Cormorant Garamond | 500, 600, 이탤릭 500 | `@fontsource/cormorant-garamond` |

- 패키지가 없거나 용량이 크면 Google Fonts에서 받아 필요한 글자만 남깁니다(`pyftsubset` 또는 `glyphhanger`). 기준: 한글 완성형 2,350자 + 영문·숫자·문장 부호.
- 앱 '정보' 화면에 글꼴 이름과 라이선스(OFL)를 표시합니다.

## 4. 아이콘

- 앱 안 아이콘: `docs/DESIGN.md` 6장의 SVG 경로를 그대로 쓰거나 **Lucide**(ISC 라이선스)로 대체합니다.
- 앱 아이콘(홈 화면): 아래 크기가 필요합니다. 디자인 방향은 '세로로 선 책 한 권 + 빗방울 하나'입니다.

| 파일 | 크기 | 비고 |
|---|---|---|
| `icon-192.png` | 192×192 | |
| `icon-512.png` | 512×512 | |
| `icon-maskable-512.png` | 512×512 | 가장자리 10% 안쪽에 그림을 두기 |
| `apple-touch-icon.png` | 180×180 | iOS |
| `favicon.svg` | — | |

종이 서재 색(바탕 `#F1EADD`, 책 `#52664B`, 빗방울 `#4A5D73`)으로 만드는 것을 추천합니다. Claude Code에게 "SVG로 앱 아이콘 초안을 만들어 줘"라고 요청한 뒤 PNG로 내보내도 됩니다.
