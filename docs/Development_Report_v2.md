- 작성일: 2026-11-02

- 이전 버전: v1 (docs/Development_Report_v1.md)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 앱 이름 | 빗소리 서재 (Rainy Library) |
| 한 줄 소개 | 책 읽는 시간을 재고(뽀모도로), 빗소리·장작·카페 소리와 내 음악을 섞어 '나만의 독서 공간'을 만들어 주는 오프라인 우선 PWA |
| 대상 사용자 | 퇴근 후 꾸준히 읽고 싶은 직장인, 전공서를 오래 읽는 수험생·대학원생, 읽은 시간과 책을 기록하는 것을 즐기는 독서 기록가 |
| 개발 기간 | 2026-11-01 ~ 2026-11-02 (0~9단계, Claude Code와 바이브 코딩) |
| 현재 상태 | **v1.1 완성**(PRD 4장 v1.0 + v1.1 범위). GitHub Pages 배포 설정 완료. 남은 것은 v1.2 기능 |
| 배포 주소 | https://poguni.github.io/rainy-library/ |

## 2. 목표 및 배경

- 책을 읽으려 해도 알림과 소음 때문에 집중이 오래가지 않고, 타이머·백색소음·음악·독서 기록 앱을 따로따로 써야 해서 번거롭습니다.
- "이 책을 언제 다 읽을까?", "나는 한 시간에 몇 쪽을 읽지?"에 답해 주는 도구가 드뭅니다.
- 그래서 **버튼 한 번으로 집중 환경(소리 + 타이머)을 켜고, 읽은 만큼 기록이 자동으로 쌓이는** 앱을 목표로 했습니다.
- 모든 데이터는 기기 안에만 저장하고, 인터넷 없이도 모든 기능이 동작하는 것을 원칙으로 삼았습니다.
- 낮에는 밝은 '종이 서재', 밤에는 어두운 '에메랄드 서재'처럼 **분위기를 고를 수 있는 두 테마**로 읽는 시간 자체를 즐겁게 만드는 것도 목표입니다.
- 학습 목표: PWA, Web Audio API, IndexedDB를 실제로 다뤄 보기.

### 3.3 실제 사용 뒤 고친 점(v1.1 이후)

- 책등 제목이 2~3줄로 잘리던 것 → 세로 한 줄 + 말줄임(…), 책등 높이 100~142px로 늘림
- 갤럭시에서 프리셋 이름을 쓸 때 키보드가 한 글자마다 닫혔다 열리던 문제 해결
- 소리 섞기 화면을 두 테마 모두 메달 방식으로 통일, 슬라이더는 손잡이를 끌 때만 움직이게
- 백업 JSON이 표지 때문에 너무 커지던 문제 → ZIP 백업으로 분리

## 4. 기술 스택 및 아키텍처

### 4.1 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Vite 8 + React 18 + TypeScript 6(strict) | 빠른 빌드, 바이브 코딩에 익숙한 조합 |
| 라우팅 | react-router-dom 7 (HashRouter) | 탭 주소·뒤로 가기 유지. GitHub Pages 같은 정적 호스팅에서도 새로고침이 깨지지 않음 |
| 스타일 | Tailwind CSS v4 + CSS 변수 토큰 | `bg-surface`, `text-ink` 같은 이름을 토큰에 연결해 테마를 변수 교체만으로 바꿈. `emerald:`·`paper:` 변형 추가 |
| 저장소 | Dexie 4 (IndexedDB) | 표지·음악 Blob까지 기기 안에 저장 |
| 오디오 | Web Audio API(직접 구현) | 환경음 5종과 음악을 하나의 AudioContext에서 실시간으로 섞고 부드럽게 페이드 |
| 엑셀 | exceljs 4 (버튼 누를 때만 불러옴) | 열 너비·날짜 형식·한글 시트가 있는 진짜 xlsx. 사용자 승인 |
| 그래프 | 직접 SVG로 그림 | Recharts 대신. 막대·달력 두 종류뿐이라 라이브러리 없이 충분(사용자 결정) |
| ZIP | 직접 구현(`lib/zip.ts`) | 백업 ZIP 만들기·읽기. 표지는 이미 압축된 그림이라 무압축 저장, 읽기는 브라우저의 `DecompressionStream` |
| 오프라인 | vite-plugin-pwa 2 (Workbox) | 앱 파일·환경음·글꼴을 설치 시 모두 저장, 새 버전 자동 반영 |
| 테스트 | Vitest + Testing Library, Playwright(수동 확인) | 순수 함수 단위 테스트와 실제 브라우저 확인 |
| 배포 | GitHub Pages + GitHub Actions | 무료, 저장소에 올리면 자동 배포 |

### 4.2 폴더 구조

```text
src/
├─ app/         라우팅, 하단 탭, 금선 테두리
├─ components/  공통 부품(BottomSheet, VolumeSlider, ChevronButton, BlobImage, PageStepper)
├─ features/
│  ├─ timer/    타이머 상태(Context), 알림음·알림, 종료·결과·완독 축하 시트
│  ├─ sound/    오디오 엔진, 믹서·음악 재생기, 프리셋, Media Session
│  ├─ library/  서재·책꽂이·책 상세·책 추가
│  ├─ stats/    그래프·독서 달력, 내보내기·백업·복원, 인쇄 화면
│  └─ settings/ 테마·타이머·알림음·화면 설정
├─ db/          Dexie 스키마와 저장 함수
├─ lib/         순수 함수(타이머, 읽기 속도, 완독일, 통계, 내보내기 형식, 엑셀 표, 테마 계산, ZIP 등)
├─ theme/       tokens.css, fonts.css, ThemeSync, applyTheme, variants/{paper,emerald}
└─ assets/      환경음(m4a), 글꼴(woff2)
scripts/        prepare-sounds.sh, subset-fonts.py, make-icons.py
.github/workflows/deploy.yml   검사→빌드→GitHub Pages 배포
```

### 4.3 핵심 구조

- **타이머**: 화면 갱신만 1초마다 하고, 시간은 항상 "구간 시작 시각 + 일시정지 누적"으로 `Date.now()`에서 계산합니다. 타이머 상태는 앱 전체 Context라 어느 탭에서도 전환·페이드가 동작합니다.
- **오디오 연결**: 환경음 레이어 → 단계 Gain(재생/정지, 휴식 페이드) → 마스터 ← 음악(`<audio>` → MediaElementSource → 음악 Gain) → Compressor → 스피커. AudioContext는 앱 전체에 하나이고, 음량 변화는 모두 `linearRampToValueAtTime`입니다.
- **데이터**: `books`, `sessions`, `presets`, `tracks`, `settings` 5개 저장소. 진행 중인 세션과 테마 사본만 `localStorage`에 둡니다(새로고침 직후 바로 보이도록).
- **테마**: `<html data-theme>`과 CSS 변수로 전환합니다. 테마마다 모양이 다른 부품은 TimerFace, SoundControls, FinishCard, BookSpine 4종뿐이고 `useThemeVariant()`로 고릅니다. 그 밖의 장식은 `emerald:` CSS 변형으로 같은 마크업에 붙입니다.
- **깜빡임 없는 첫 화면**: `index.html`의 짧은 인라인 스크립트가 React보다 먼저 localStorage 사본으로 테마('자동' 포함)를 계산해 칠하고, 주소창 색(`theme-color`)도 맞춥니다. 이후 `ThemeSync`가 IndexedDB 설정과 맞춥니다.
- **백업 ZIP**: `backup.json`(책·세션·프리셋·설정, 표지는 경로만) + `covers/책ID.jpg`. 복원은 ZIP·표지 없는 JSON·예전 base64 JSON을 모두 받고, 표지 없는 백업이면 기기에 있던 표지를 지우지 않습니다.

## 6. 주요 의사결정과 이유

| 결정 | 이유 |
|---|---|
| 그래프는 라이브러리 없이 SVG로 직접 | 막대·달력 두 종류뿐. Recharts(약 100KB) 대신 가볍게, 테마 토큰도 그대로 씀(사용자 선택) |
| 엑셀은 exceljs, 버튼 누를 때만 불러옴 | CSV는 한글 깨짐·열 너비 문제. 큰 라이브러리(gzip 258KB)라 첫 화면에는 넣지 않음(사용자 승인) |
| PDF는 인쇄 화면 + 브라우저 'PDF로 저장' | PDF 라이브러리 없이 A4 인쇄용 CSS로 해결, 한글 글꼴 문제도 없음 |
| 음악은 원본 파일을 IndexedDB에 저장 | 오프라인 우선. 파일은 기기 밖으로 나가지 않음 |
| 음악도 같은 AudioContext 마스터에 연결 | 전체 음량·휴식 페이드가 음악에도 똑같이 적용 |
| 테마 전용 부품 4종 외에는 CSS 변형(`emerald:`)으로 장식 | CLAUDE.md 규칙(부품 4종) 유지, 두 테마가 같은 마크업·같은 동작 |
| 테마 사본을 localStorage에 | IndexedDB는 비동기라 첫 화면에 늦음 → 인라인 스크립트가 바로 읽어 깜빡임 없음 |
| 자동 테마는 앱으로 돌아올 때만 다시 계산 | 읽는 도중 갑자기 색이 바뀌지 않도록 |
| 글꼴을 굵기 1~2개로 줄임(Noto Serif KR 600, Plex 400) | 에메랄드 글꼴 예산. 700은 600으로 대신 |
| 배포는 GitHub Pages(2026-11-02 사용자 결정) | 무료, 저장소 푸시만으로 자동 배포. `BASE_PATH`로 하위 경로 대응 |
| 소리 섞기 UI를 메달 방식으로 통일(사용자 요청) | 종이 테마의 한 줄 슬라이더는 휴대폰에서 스크롤과 겹쳐 조작이 어려웠음 |
| 슬라이더는 손잡이만 터치를 받음 | 스크롤하다 막대를 스쳐 값이 바뀌고 소리가 켜지던 문제. 손잡이 누르는 영역은 40px |
| 백업은 ZIP 하나 + 표지 없는 JSON(사용자가 C안 선택) | 표지를 base64로 넣으면 JSON이 수십 MB. ZIP 하나면 복원 파일도 하나라 헷갈리지 않음 |
| ZIP은 직접 구현 | 무압축 저장은 간단하고, 다시 압축한 ZIP도 브라우저 기능으로 풂. 새 라이브러리 없음 |
| 음원 출처를 사운드 탭 아래 간단히 표기 | 사용자 요청: "[출처] 유튜브 채널명" 형식(제작자 답변을 기다리는 동안) |

## 7. 문제 해결 기록

| 문제 | 원인 | 해결 |
|---|---|---|
| 북카페 프리셋이 선택된 것으로 표시되지 않음 | 빠진 소리를 기본 조합(장작 켜짐)으로 채움 | 프리셋에 5종을 모두 명시 |
| 백업 복원 안내 문구가 덮어써짐 | 공통 실행 함수가 고정 문구를 보여 줌 | 작업이 돌려준 문장을 그대로 보여 주게 |
| 에메랄드 숫자가 들쭉날쭉 | Cormorant 기본 숫자가 옛 숫자(old-style) | `font-feature-settings: 'lnum'` |
| 글꼴 용량 초과 | 굵기를 여러 개 넣음 | Noto 700·Plex 500 제외, 서브셋 스크립트에 굵기 고정·라틴 전용 옵션 |
| 로컬 하위 경로 빌드가 Windows 경로로 바뀜 | Git Bash가 `/rainy-library/`를 경로로 변환 | `MSYS_NO_PATHCONV=1` |
| 확인 중 옛 버전이 보임 | 같은 포트에 예전 서비스 워커가 남음 | 등록 해제·캐시 삭제 후 확인 |
| **갤럭시에서 키보드가 한 글자마다 닫혔다 열림** | 사운드 탭이 다시 그려질 때마다 `onClose`가 새 함수 → 바텀 시트 effect가 다시 실행되어 포커스를 버튼으로 돌렸다가 입력칸으로 옮김 → 한글 조합이 끊김 | effect는 열릴 때 한 번만, 최신 `onClose`는 ref로. 재현 테스트를 먼저 써서 실패 확인 후 수정 |
| **스크롤하다 슬라이더가 움직이고 소리가 켜짐** | 막대 어디든 닿으면 값이 그 자리로 이동, 음량 > 0이면 켜짐 | 막대는 `pointer-events: none`, 손잡이만 터치, `touch-action: pan-y` |
| 책등 제목이 2~3줄로 잘림 | 세로쓰기 칸보다 제목이 길면 옆 줄로 넘어감 | 한 줄 + `text-overflow: ellipsis`, 자간 1px, 높이 +14px |
| PC에서 선반에 세로 스크롤바 | 가로 스크롤바 높이만큼 칸이 좁아짐 | `overflow-y: hidden` |
| 백업 JSON이 너무 큼 | 원본 표지 사진(장당 수 MB)을 base64(+33%)로 넣음 | ZIP 백업으로 분리 |

## 8. 보안·개인정보·성능

- **개인정보**: 책·세션·설정·음악·표지는 모두 기기(IndexedDB·localStorage)에만 저장합니다. 외부 서버 전송, 분석 도구, 광고 SDK가 없습니다. 백업·내보내기 파일도 기기 안에서 만들어 바로 내려받습니다.
- **외부 요청 없음**: 글꼴·아이콘·음원을 모두 앱에 포함해, 설치 후에는 네트워크 요청이 필요 없습니다.
- **설치 용량**: 사전 캐시 29개 파일, 약 6.3MB(대부분 환경음·글꼴·엑셀 모듈). 첫 화면 JS 389KB(gzip 123KB), 엑셀 모듈은 따로 932KB(gzip 258KB)로 버튼을 누를 때만 불러옵니다.
- **메모리**: 환경음은 켜진 것만 디코딩합니다.
- **개발용 기능 분리**: 샘플 데이터 버튼과 `window.__soundEngine`·`__musicPlayer`는 개발 모드에서만 존재합니다.

## 11. 알려진 한계

- **표지 원본 크기**: 표지를 고른 사진 그대로 저장해 장당 수 MB일 수 있습니다. 기기 저장 공간과 전체 백업 ZIP이 커집니다.
- **책등 제목**: 긴 제목은 앞 5~8자만 보입니다(상세 카드에는 전체 제목).
- **책등 폭**: DESIGN.md의 26~42px를 따라 누르는 영역이 44px보다 좁습니다.
- **음악 파일은 백업에 없음**: 용량 때문에 빠집니다. 새 기기에서는 다시 불러와야 합니다.
- **새로고침 후 소리**: 타이머는 이어지지만 소리는 브라우저 자동 재생 정책 때문에 다시 켜야 합니다.
- **글꼴 용량**: 종이 약 506KB, 에메랄드 약 510KB로 PRD 목표(테마당 300KB)를 넘습니다. 테마별로 필요한 글꼴만 불러오지는 않습니다.
- **DB 연동 화면 테스트 없음**: jsdom에 IndexedDB가 없어 저장 흐름은 브라우저에서 수동 확인했습니다.
- **Lighthouse 점수**: 기록이 없는 화면에서 잰 값입니다.
- **시스템 알림**: iOS는 홈 화면에 설치한 경우에만 됩니다. 화면 꺼짐 방지는 지원 브라우저에서만 동작합니다.

### 12.1 ⚠️ 확인이 필요한 일 (잊지 말 것)

- **환경음 5종 저작권 재확인(제작자 답변 대기 중)**

- **공개 배포 허락 여부**
  - 무료 GitHub Pages는 **공개 저장소**에서만 쓸 수 있어, 배포하면 음원 파일(`src/assets/sounds/`)을 누구나 내려받을 수 있습니다.
  - 제작자에게 "앱에 넣어 공개 배포해도 되는지"를 함께 물어봐야 합니다. 저장소가 지금 공개인지는 확인하지 못했습니다(`gh` 명령 없음).
  - 불확실하면: 비공개 저장소 + Netlify/Vercel 배포, 또는 CC0 음원으로 교체.
  - 답을 받으면 `docs/ASSETS.md` 출처 표를 확정합니다.
